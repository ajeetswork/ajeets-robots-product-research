# New Category Product Onboarding Standard

> Ajeets Robots / Printify  
> Version 1.0 – 2026-07-20  
> This document defines the minimum information that must be reviewed and confirmed before Ajeets Robots launches products in a new category.

---

## 1. Product Title

- [ ] Full product name includes brand prefix: **"Ajeets Robots - …"**
- [ ] Title is specific and descriptive (not generic like "Phone Stand" or "Pet Tag")
- [ ] No spelling errors or typos in the title
- [ ] Title matches the product type / blueprint in Printify
- [ ] Title is consistent with naming conventions used in existing categories
- [ ] Title is under the Printify / sales channel character limit

---

## 2. Product Description

- [ ] Description is not a placeholder (e.g. "This is a Pet Tag.", "Phone Stand", "This is a classic water bottle")
- [ ] Description is at least 150 characters and ideally 300–800 characters
- [ ] Description includes: what the product is, key features, materials, size/dimensions, and intended use
- [ ] Description is written in plain, accessible language (no single 800+ character paragraph wall)
- [ ] Features are separated from specifications — use headings or bullet lists where appropriate
- [ ] All factual claims in the description are verified against the Printify / supplier product spec sheet
- [ ] If the product is part of the **Ajeets Robots FUN-RAISER collection**, the description calls this out with a link to the fundraiser
- [ ] No unsupported claims (materials, certifications, performance, compatibility, safety)

### Description completeness checklist
- [ ] What it is — 1–2 sentence product summary
- [ ] Key features — bulleted list
- [ ] Specifications — materials, dimensions, weight, capacity, etc.
- [ ] Care instructions — if applicable (see §6)
- [ ] What's included / what's not included (e.g. "pillow insert not included", "hooks not included")

---

## 3. Pricing

- [ ] Retail price is set for every enabled variant
- [ ] Price ending is consistent with the Ajeets Robots pricing standard for the category:
  - Standard retail: **`.99`**
  - Premium / high-end: **`.00`**
  - Alternative retail: **`.95`**
  - Avoid irregular cent endings (e.g. `.48, .73, .83, .17`) unless there is a documented reason
- [ ] All variants within the same product use the **same price-ending style** (no mix of `.00`, `.99`, `.13`, `.76` etc. across variants of one product)
- [ ] Price is consistent with comparable products in the Ajeets Robots catalog
- [ ] Profit margin has been reviewed against Printify production cost
- [ ] Sale / promotional pricing (if any) follows the same ending convention

---

## 4. Variants

- [ ] All intended size / color / material / finish variants are created in Printify
- [ ] Each variant has an accurate, descriptive name (e.g. "White / One size", "28\" × 18\"", "1.4\" × 2.8\" / Glossy")
- [ ] Each variant has the correct retail price assigned
- [ ] Each variant has the correct SKU / product code if applicable
- [ ] Only variants that are actually available for sale are **enabled** — disabled variants should be intentional, not accidental
- [ ] If variants are disabled, document why (e.g. "Matte finish on backorder", "XL size not launching in wave 1")
- [ ] At least one variant is enabled before the product is published
- [ ] Variant-level images exist for materially different options (color, material, size) where applicable

---

## 5. Compatibility Information

Complete where applicable to the product category. Check all that apply:

### Physical compatibility
- [ ] Dimensions are listed with units (in / cm)
- [ ] Weight / capacity is listed where relevant
- [ ] Fits / compatibility notes are included (e.g. phone case model compatibility, pet bed weight limit, backpack laptop sleeve size)

### Technology / electronics
- [ ] Bluetooth version, pairing method, supported profiles
- [ ] Battery capacity, charging time, charge cycles
- [ ] Supported devices / operating systems
- [ ] Ports, cables included / required
- [ ] Wireless standards (Qi, etc.)

### Apparel / wearables
- [ ] Size chart with measurements (chest, length, etc.)
- [ ] Fit notes (true to size, relaxed fit, etc.)
- [ ] Available sizes and colors clearly listed

### Pet products
- [ ] Species / breed size suitability
- [ ] Weight capacity (beds, carriers)
- [ ] Bowl capacity in oz / ml
- [ ] Material safety for animals (BPA-free, food-grade, etc.)

### Home / drinkware
- [ ] Capacity in oz / ml
- [ ] Dishwasher / microwave / freezer safe status
- [ ] Material (ceramic, stainless steel, BPA-free, etc.)

> **Rule:** If a customer could buy the wrong variant because compatibility information is missing, the listing is not ready.

---

## 6. Care Instructions

Include where applicable to the product category:

### Apparel / textiles
- [ ] Washing temperature and method (machine wash cold, hand wash, etc.)
- [ ] Drying method (tumble dry low, hang dry, lay flat)
- [ ] Ironing guidance (temperature, "do not iron directly on print")
- [ ] Bleach / dry clean / fabric softener guidance
- [ ] Turn inside out before washing (for printed designs)

### Drinkware / ceramics
- [ ] Dishwasher safe Y/N
- [ ] Microwave safe Y/N
- [ ] Hand-wash recommendations if applicable

### Electronics
- [ ] Charging instructions
- [ ] Water / dust resistance rating (IPX) if applicable
- [ ] Storage / temperature guidance
- [ ] Battery care

### Pet products
- [ ] Washing instructions for fabric items (removable cover? machine washable?)
- [ ] Dishwasher safe status for bowls / feeders
- [ ] Replacement / wear indicators if applicable

### Home decor / other
- [ ] Cleaning method (spot clean, wipe with damp cloth, etc.)
- [ ] Sunlight / moisture / heat exposure warnings
- [ ] Assembly / hanging instructions if applicable

> **Formatting:** Care instructions must be in their own clearly labeled section, separate from marketing copy. Use a bulleted list — one instruction per bullet. Do not bury care steps mid-paragraph.

---

## 7. Safety Information

Complete where applicable to the product category and target market:

### General
- [ ] Age recommendations / warnings (e.g. "Not suitable for children under 3")
- [ ] Choking hazard warnings for small parts
- [ ] California Prop 65 / REACH / CPSIA compliance statements where required
- [ ] Country of origin if required by sales channel

### Electronics
- [ ] FCC / CE / RoHS compliance
- [ ] Battery safety warnings (do not puncture, dispose properly, etc.)
- [ ] Charging safety (use approved chargers only)
- [ ] Hearing safety notice for audio products (safe listening volume)

### Pet products
- [ ] Supervised use recommendation where appropriate
- [ ] Material safety confirmation (non-toxic, BPA-free, food-grade)
- [ ] Size appropriateness warning (e.g. "Choose size based on pet weight")
- [ ] Cleaning frequency recommendation for food/water bowls

### Children's products
- [ ] Age grading
- [ ] Small parts / choking hazard warnings
- [ ] CPSIA / EN71 / ASTM compliance if applicable
- [ ] Flammability warnings where required

### Drinkware / food contact
- [ ] Food-grade / BPA-free confirmation
- [ ] Hot liquid warnings if applicable
- [ ] Not for stovetop / oven use (where applicable)

### Textiles / apparel
- [ ] Flammability warnings where required
- [ ] Drawstring / strangulation warnings for children's apparel
- [ ] Allergen information (e.g. latex, nickel) if applicable

> **Rule:** If a safety claim, warning, or certification appears in the listing, it must be verified against the Printify supplier / manufacturer documentation. Remove any safety claim that cannot be verified.

---

## 8. Pre-Publish Checklist

Before a new-category product is marked **Ready to Promote**:

- [ ] **Title** — complete, accurate, follows naming convention (§1)
- [ ] **Description** — complete, not placeholder, includes features/specs/care (§2)
- [ ] **Pricing** — consistent ending style, margin reviewed (§3)
- [ ] **Variants** — all intended variants created, correctly priced, enabled/disabled status is intentional (§4)
- [ ] **Compatibility** — all applicable compatibility information is present and accurate (§5)
- [ ] **Care instructions** — present, in a dedicated section, properly formatted (§6)
- [ ] **Safety information** — all applicable warnings and compliance statements are present and verified (§7)
- [ ] **Images** — at least 2 product images (ideally 4+), including variant-specific images where applicable
- [ ] **Tags** — product is tagged for search/discovery in Printify
- [ ] **Sales channels** — product is connected to the appropriate sales channel(s)
- [ ] **Factual review** — all product claims verified against Printify / supplier spec sheets
- [ ] **FUN-RAISER flag** — if applicable, product is marked as part of the Ajeets Robots FUN-RAISER collection in the description
- [ ] **Price ending audit** — product price ending(s) match the Ajeets Robots pricing standard
- [ ] **Onboarding record** — product is logged in the [New Category Product Onboarding](https://app.notion.com/p/b4672406b82e404ebdd4297aae67470e) Notion database with status updated
